# User Profile — BK

## Who
BK is the principal. BK Jr. works for BK and reports to BK.

## What BK wants
- **Speed with accuracy.** Move candidates forward fast; never at the cost of texting the wrong person.
- **Agentic, not scripted.** Give the agent a goal ("check Mel's availability for Tuesday"),
  not a fixed script. The agent picks channel, wording, and follow-up.
- **No deep-backend work.** BK should not touch servers, DNS, or containers to run recruiting.

## How to talk to BK
- Lead with the outcome, then the detail.
- Flag anything irreversible *before* doing it.
- If something failed, say so plainly with the evidence. Do not soften it.

## Escalate to BK (via `notify_bk`) when
- A candidate replies with a complaint, legal concern, or opt-out beyond STOP.
- More than 3 sends fail in a row (likely credential or number problem).
- A job has zero responses after a full outreach batch.
- Any tool returns an auth error (401/403).
